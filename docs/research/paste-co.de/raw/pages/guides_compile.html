How to compile (for the PMRs)

Introduction

Compiling a project from source is the process of converting human-readable code into an executable file that your computer can run. This guide covers the common compilation workflow for C++ projects shared on Paste-co.de.

1. Prerequisites: Visual Studio

Almost all C++ based game security projects require Microsoft Visual Studio. While other IDEs exist, Visual Studio provides the most robust toolchain for Windows-based development.

Get the Community Edition (which is free) here: https://visualstudio.microsoft.com/

Important Note:When installing, make sure to select the "Desktop development with C++" workload in the installer, otherwise you will be missing the necessary compilers and libraries.

2. Opening & Configuring the Solution

After downloading the project source, look for a .sln (Solution) or .slnx file. Double-clicking this will open the entire project in Visual Studio.

  • Solution Configuration: Look at the top toolbar. By default, it might say "Debug". Change this to Release for optimal performance and smaller file size.
  • Solution Platform: Next to the configuration, ensure it is set to x64 (or x86 if the project is specifically 32-bit).
  • Build Command: Once configured, press the green "Play" button or go to Build - Build Solution.

Troubleshooting Common Errors

"MSB8020: The build tools... cannot be found"

This happens when the project was made with an older (or newer) version of Visual Studio. Right-click the Project in the Solution Explorer, select Retarget Projects, and select your current SDK version.

"Cannot open include file: '...': No such file or directory"

You are likely missing a library. Check if the project uses a package manager like Vcpkg or NuGet, or if it requires external SDKs like the DirectX SDK.

If you get errors relating to the logic of the source itself, fixing them often requires deep technical knowledge of the codebase.
