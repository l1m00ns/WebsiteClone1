<section id="overview">
<h2 class="mb-3 text-sm font-semibold text-foreground">Overview</h2>
<div class="prose-legal">
<p>paste-co.de hosts files submitted by community members. All submissions go through a human admin review queue before being published. This page explains our review process and your responsibilities as a downloader.</p>
</div>
</section>
<section id="review-process">
<h2 class="mb-3 text-sm font-semibold text-foreground">Review Process</h2>
<div class="prose-legal">
<p>When a project is submitted, it enters a pending queue only visible to admins. An admin will inspect the submission — checking the link, description, and metadata — before approving and publishing it to the archive.</p>
<p>Submissions that contain malicious content, violate our<!-- --> <a href="/terms">Terms of Service</a>, or are otherwise inappropriate will be rejected and deleted without notice.</p>
</div>
</section>
<section id="your-responsibility">
<h2 class="mb-3 text-sm font-semibold text-foreground">Your Responsibility as a Downloader</h2>
<div class="prose-legal">
<p>
<strong>You download and run files entirely at your own risk.</strong> We strongly recommend:</p>
<ul>
<li>Running downloaded files in a <strong>virtual machine or sandbox</strong> before executing on your main system.</li>
<li>Scanning files with your own antivirus software before opening them.</li>
<li>Reading the project description and checking any linked source code before downloading.</li>
<li>Never running any executable you do not understand.</li>
</ul>
</div>
</section>
<section id="reporting">
<h2 class="mb-3 text-sm font-semibold text-foreground">Reporting Malicious Content</h2>
<div class="prose-legal">
<p>If you believe a file on paste-co.de is malicious or harmful, please report it immediately in our<!-- --> <a href="https://discord.gg/macrostack" target="_blank" rel="noopener noreferrer">Discord server</a>. Include the project name, URL, and a description of your concern. We will investigate and remove the file if confirmed.</p>
</div>
</section>

<p>paste-co.de and its operators disclaim all liability for any harm resulting from files downloaded from this site. All content is provided for educational purposes only. See our <a href="/terms">Terms of Service</a> for full details.</p>
