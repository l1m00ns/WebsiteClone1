<h1 class="font-display text-xl font-medium tracking-tight text-foreground md:text-3xl">Troubleshooting</h1>
</div>
</div>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<div class="mb-4 flex items-center gap-2">
<svg/>
<h2 class="text-lg font-semibold text-card-foreground">MSB8020 Error</h2>
</div>
<p class="text-sm leading-relaxed text-muted-foreground">Make sure WDK is installed fully and correctly.</p>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<h2 class="mb-4 text-lg font-semibold text-card-foreground">Can&#x27;t find pattern</h2>
<p class="mb-2 text-sm leading-relaxed text-muted-foreground">If KDMapper fails and the log contains <code>Can&#x27;t find pattern</code> the one of following reasons may occurred:</p>
<ul class="mb-4 list-disc space-y-2 pl-5 text-sm text-muted-foreground">
<li>Your KDMapper version is outdated. Ensure you build the newest KDMapper from<!-- --> <a href="https://github.com/TheCruZ/kdmapper" target="_blank" rel="noreferrer" class="text-primary hover:underline">https://github.com/TheCruZ/kdmapper</a> <!-- -->and try again.</li>
<li>Your Windows version is outdated. Try to update your Windows to the newest version. Afterwards try again.</li>
<li>KDMapper does not support your Windows version.</li>
</ul>
<p class="text-sm text-muted-foreground">You may use another mapping method as described in the Mapper guides.</p>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<h2 class="mb-4 text-lg font-semibold text-card-foreground">Nal is already in use</h2>
<div class="mb-4 glass-well rounded-[16px] border border-transparent p-3 font-mono text-xs text-muted-foreground/80 backdrop-blur-sm">[-] \Device\Nal is already in use.</div>
<p class="text-sm leading-relaxed text-muted-foreground">Use: <a href="https://github.com/VollRagm/NalFix" target="_blank" rel="noreferrer" class="text-primary hover:underline">https://github.com/VollRagm/NalFix</a>
</p>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<h2 class="mb-4 text-lg font-semibold text-card-foreground">Additional Troubleshooting Steps</h2>
<p class="mb-2 text-sm leading-relaxed text-muted-foreground">If none of the errors above happened, the following general things may help:</p>
<ul class="list-disc space-y-2 pl-5 text-sm text-muted-foreground">
<li>Check that your path does not contain any spaces/invalid characters (aka. non-ascii characters).</li>
<li>Check for interfering Windows security features (&quot;How to disable windows security features for driver loading&quot;).</li>
<li>
<strong>Check for applications which may block KDMapper:</strong> Vanguard and other anticheats (Faceit, etc.) will instantly load the second your PC boots. Meaning KDMapper will be blocked from loading your driver.</li>
</ul>
</section>
<section class="glass rounded-[24px] p-4 md:p-5">
<div class="mb-4 flex items-center gap-2">
<svg/>
<h2 class="text-lg font-semibold text-destructive/90 uppercase">MSB4062</h2>
</div>
<p class="mb-6 font-mono text-xs font-bold text-destructive">FOR PEOPLE WHO CAN&#x27;T READ: DOWNGRADE TO VS2022</p>
<div class="mb-6 glass-well rounded-[16px] border border-transparent p-3 text-sm text-muted-foreground/80 backdrop-blur-sm">
<p class="mb-2 font-mono">The &quot;ValidateNTTargetVersion&quot; task could not be loaded (MSB4062)</p>
<p>If Visual Studio throws an error stating <code>The &quot;ValidateNTTargetVersion&quot; task could not be loaded from the assembly...</code> and references <code>Microsoft.DriverKit.Build.Tasks.18.0.dll</code>, it means your WDK (Windows Driver Kit) installation is corrupted, missing dependencies, or mismatched with your Windows SDK version.</p>
</div>
<div class="space-y-6">
<div>
<h3 class="mb-2 font-semibold text-card-foreground">1. Ensure SDK and WDK Versions Match Exactly</h3>
<p class="mb-2 text-sm text-muted-foreground">The WDK requires the exact matching version of the Windows SDK to compile drivers.</p>
<ol class="list-decimal space-y-1 pl-5 text-sm text-muted-foreground">
<li>Open the <strong>Visual Studio Installer</strong>.</li>
<li>Click <strong>Modify</strong> on Visual Studio 2022.</li>
<li>On the right side under &quot;Installation details&quot;, expand <strong>Desktop development with C++</strong>.</li>
<li>Scroll down and make sure your Windows 11 SDK version matches the version in the error path (e.g., <strong>10.0.26100.0</strong>). If it isn&#x27;t, check it and install it.</li>
</ol>
</div>
<div>
<h3 class="mb-2 font-semibold text-card-foreground">2. Verify the WDK Visual Studio Extension is Enabled</h3>
<p class="mb-2 text-sm text-muted-foreground">Sometimes the WDK installs on your computer, but the plugin for Visual Studio fails to enable.</p>
<ol class="list-decimal space-y-1 pl-5 text-sm text-muted-foreground">
<li>Open Visual Studio.</li>
<li>Go to <strong>Extensions</strong> <!-- -->-&gt;<!-- --> <strong>Manage Extensions</strong> at the top.</li>
<li>Click on <strong>Installed</strong> on the left.</li>
<li>Look for <strong>Windows Driver Kit</strong>.</li>
<li>If it is disabled, enable it. (If it is not there at all, your WDK did not install correctly into Visual Studio).</li>
</ol>
</div>
<div>
<h3 class="mb-2 font-semibold text-card-foreground">3. Repair the WDK Installation</h3>
<p class="mb-2 text-sm text-muted-foreground">If the SDK matches and the extension is there, the actual <code>.dll</code> file the compiler is looking for is legitimately missing or corrupted on your hard drive.</p>
<ol class="list-decimal space-y-1 pl-5 text-sm text-muted-foreground">
<li>Go to <strong>Add or Remove Programs</strong> (or Installed Apps) in Windows settings.</li>
<li>Search for <strong>Windows Driver Kit</strong>.</li>
<li>Click the three dots (or right-click) and select <strong>Modify</strong> or <strong>Repair</strong>.</li>
<li>Let the installer run purely as a Repair operation. It will redownload and replace the missing dll.</li>
</ol>
</div>
<div>
<h3 class="mb-2 font-semibold text-card-foreground">4. Ensure Spectre Mitigations are Installed (Bonus fix)</h3>
<p class="mb-2 text-sm text-muted-foreground">WDK projects require Spectre-mitigated libraries enabled by default. While you are in the Visual Studio Installer (from Step 1), make sure you also checked:</p>
<ul class="mb-2 list-disc pl-5 text-sm text-muted-foreground">
<li>
<strong>MSVC v143 - VS 2022 C++ x64/x86 Spectre-mitigated libs (Latest)</strong>
</li>
</ul>
<p class="text-sm text-muted-foreground">After checking these, restart Visual Studio, make sure you have <strong>Release | x64</strong> selected at the top, and try hitting <code>Ctrl+Shift+B</code> again.</p>
</div>
</div>
