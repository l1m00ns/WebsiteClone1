<p class="font-display text-3xs uppercase tracking-widest text-muted-foreground">Guides / Compile (PMRs)</p>
<h1 class="font-display text-xl font-medium tracking-tight text-foreground md:text-3xl">How to compile (for the PMRs)</h1>
</div>
</div>
<section class="mb-8 space-y-4 glass rounded-[24px] p-6">
<div class="space-y-2">
<h2 class="text-lg font-semibold text-card-foreground">Introduction</h2>
<p class="text-sm leading-relaxed text-muted-foreground">Compiling a project from source is the process of converting human-readable code into an executable file that your computer can run. This guide covers the common compilation workflow for C++ projects shared on Paste-co.de.</p>
</div>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<div class="mb-4 flex items-center gap-2">
<svg/>
<h2 class="text-sm font-semibold text-card-foreground">1. Prerequisites: Visual Studio</h2>
</div>
<p class="text-sm leading-relaxed text-muted-foreground mb-4">Almost all C++ based game security projects require Microsoft Visual Studio. While other IDEs exist, Visual Studio provides the most robust toolchain for Windows-based development.</p>
<p class="text-sm leading-relaxed text-muted-foreground">Get the Community Edition (which is free) here:<!-- --> <a href="https://visualstudio.microsoft.com/" target="_blank" rel="noreferrer" class="text-primary underline-offset-4 hover:underline">https://visualstudio.microsoft.com/</a>
</p>
<div class="mt-4 rounded-lg bg-primary/5 p-4 text-xs text-primary/80 border border-primary/10">
<strong class="block mb-1">Important Note:</strong>When installing, make sure to select the <strong>&quot;Desktop development with C++&quot;</strong> workload in the installer, otherwise you will be missing the necessary compilers and libraries.</div>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<div class="mb-4 flex items-center gap-2">
<svg/>
<h2 class="text-sm font-semibold text-card-foreground">2. Opening &amp; Configuring the Solution</h2>
</div>
<p class="text-sm leading-relaxed text-muted-foreground mb-4">After downloading the project source, look for a <code>.sln</code> (Solution) or <code>.slnx</code> file. Double-clicking this will open the entire project in Visual Studio.</p>
<ul class="space-y-3 pl-5 text-sm text-muted-foreground">
<li class="list-disc">
<strong>Solution Configuration:</strong> Look at the top toolbar. By default, it might say &quot;Debug&quot;. Change this to <strong>Release</strong> for optimal performance and smaller file size.</li>
<li class="list-disc">
<strong>Solution Platform:</strong> Next to the configuration, ensure it is set to <strong>x64</strong> (or x86 if the project is specifically 32-bit).</li>
<li class="list-disc">
<strong>Build Command:</strong> Once configured, press the green &quot;Play&quot; button or go to <code>Build - Build Solution</code>.</li>
</ul>
</section>
<section class="mb-6 glass rounded-[24px] p-4 md:p-5">
<div class="mb-4 flex items-center gap-2 text-destructive">
<svg/>
<h2 class="text-sm font-semibold text-card-foreground">Troubleshooting Common Errors</h2>
</div>
<div class="space-y-4">
<div class="space-y-2">
<h3 class="text-xs font-bold text-foreground uppercase tracking-tight">&quot;MSB8020: The build tools... cannot be found&quot;</h3>
<p class="text-xs text-muted-foreground leading-relaxed">This happens when the project was made with an older (or newer) version of Visual Studio. Right-click the Project in the Solution Explorer, select <strong>Retarget Projects</strong>, and select your current SDK version.</p>
</div>
<div class="space-y-2">
<h3 class="text-xs font-bold text-foreground uppercase tracking-tight">&quot;Cannot open include file: &#x27;...&#x27;: No such file or directory&quot;</h3>
<p class="text-xs text-muted-foreground leading-relaxed">You are likely missing a library. Check if the project uses a package manager like Vcpkg or NuGet, or if it requires external SDKs like the DirectX SDK.</p>
</div>
</div>
<div class="mt-6 glass-well rounded-[16px] border border-transparent p-4 text-xs text-muted-foreground/80 backdrop-blur-sm italic">
<p>If you get errors relating to the logic of the source itself, fixing them often requires deep technical knowledge of the codebase.</p>
</div>
</section>
