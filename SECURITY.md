# Security Policy

This repository is a **static, read-only clone** of paste-co.de. It has no backend, database, file storage,
or authentication, and it does not execute or distribute any downloaded files.

## Reporting a vulnerability

If you find a security issue in the Next.js application or its dependencies, please use GitHub's private
[Report a vulnerability](https://github.com/l1m00ns/WebsiteClone1/security/advisories/new) form.
Do not disclose sensitive details in a public issue.

## Scope

In scope:

- HTML injection or XSS in the rendered guide and legal content
- Vulnerabilities in the application code or dependencies
- Build or deployment misconfiguration in this repository

Out of scope:

- The original paste-co.de service, its API, or its content
- Third-party links and downloads referenced by the archived content
